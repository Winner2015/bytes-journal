

## ExtensionLoader

ExtensionLoader启动时，依赖JDK的SPI机制，加载LoadingStrategy的实现类：

META.INF.service:

```
org.apache.dubbo.common.extension.DubboInternalLoadingStrategy 
//加载：META-INF/dubbo/internal/org.apache.dubbo.common.extension.ExtensionFactory

org.apache.dubbo.common.extension.DubboLoadingStrategy
//META-INF/dubbo/internal/com.alibaba.dubbo.common.extension.ExtensionFactory


org.apache.dubbo.common.extension.ServicesLoadingStrategy
//META-INF/services/org.apache.dubbo.common.extension.ExtensionFactory

```

三者类似，估计是为了兼容以前的版本，就是加载ExtensionFactory

得到三个键值对配置，也就是三个ExtensionFactory的子类：

```
adaptive=org.apache.dubbo.common.extension.factory.AdaptiveExtensionFactory
spi=org.apache.dubbo.common.extension.factory.SpiExtensionFactory


还有：
spring=org.apache.dubbo.config.spring.extension.SpringExtensionFactory
```

三个类被加载后，缓存起来，AdaptiveExtensionFactory比较特殊，单独存储
